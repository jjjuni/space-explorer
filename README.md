# 🌌 Space Explorer

<br/>

Three.js를 활용해 제작한 **인터랙티브 우주 탐험 프로젝트**입니다.

우주 공간을 직접 이동하며 태양과 행성을 탐험할 수 있도록 구현했습니다.
행성의 자전과 공전, 달의 공전, 카메라 이동 및 마우스 시점 조작 등의 기능을 구현하며 Three.js의 3D 공간과 객체 간 관계를 경험하는 것을 목표로 했습니다.

## 🛠️ Tech Stack

* React
* TypeScript
* Three.js
* Vite

## ✨ 주요 기능

* 우주 공간 구현
* 태양과 행성 렌더링
* 행성 자전 및 공전
* 달의 지구 중심 공전
* WASD 카메라 이동
* 마우스 기반 시점 조작
