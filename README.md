Three.js를 활용해 제작한 **인터랙티브 우주 탐험 프로젝트**입니다.

우주 공간을 직접 이동하며 태양과 여러 행성을 탐험하고, 원하는 행성을 가까이에서 관찰할 수 있도록 구현했습니다.
행성의 자전과 공전, 달의 공전부터 카메라 이동과 시점 조작, 행성 Focus, 워프 연출과 우주 배경까지 구현하며 Three.js의 3D 공간과 객체 간 관계를 경험하는 것을 목표로 했습니다.

## 🛠️ Tech Stack

* React
* TypeScript
* Three.js
* Vite

## ✨ 주요 기능

* **인터랙티브 우주 공간**

  * 태양, 행성, 달을 포함한 3D 우주 공간 구현
  * 별과 성운을 활용한 우주 배경 구성

* **천체의 자전 및 공전**

  * 행성의 자전 및 태양 중심 공전
  * 달의 지구 중심 공전
  * 행성별 공전 궤도 표시

* **자유로운 우주 탐험**

  * WASD를 이용한 카메라 이동
  * SPACE / C를 이용한 상하 이동
  * 마우스를 이용한 자유로운 시점 조작

* **행성 Focus 모드**

  * 행성에 접근하면 Focus 기능 활성화
  * F 키를 이용해 원하는 행성의 Focus 모드 진입
  * 행성의 공전 움직임을 따라가며 가까이에서 관찰
  * 행성의 기본 정보 표시

* **Warp Drive 연출**

  * 우주 공간 진입을 위한 워프 로딩 화면 구현
  * 워프 속도 변화와 별의 이동을 활용한 가속 연출
  * 워프 종료 후 실제 우주 공간으로 자연스럽게 전환

* **3D 모델 로딩 및 화면 전환**

  * GLB 기반 행성 모델 로딩
  * 모델 로딩 중 별도의 Warp Scene 표시
  * 모든 주요 행성 로딩 완료 후 실제 우주 공간으로 전환
